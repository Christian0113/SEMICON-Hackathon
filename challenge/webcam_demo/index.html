Network is the round trip minus everything the server says it spent, so it is the camera, the JPEG encode, the internet both ways and the drawing. Both halves of that subtraction are durations, each measured on its own machine's clock, so the two clocks do not have to agree. Capture + encode is measured in this page and is already inside the round trip; it is shown separately so you can see how much of the "network" is not actually network. Every frame's numbers are also posted back to the server and appended to a file, so a run can be summarised afterwards rather than read off this panel. On the machine is the JPEG decode plus the detection, and it is the only figure here that would still exist if the card were bolted to a robot. Queue wait is this page having several frames in flight at once while the card takes them one at a time, so it grows with MAX_IN_FLIGHT and is not a property of the hardware. Round trip adds the camera, the JPEG encode and the internet in both directions, none of which a real machine pays. Frames are squashed to a square before they are sent, which is what the model's own image loader does, so the boxes map straight back onto the full picture.
